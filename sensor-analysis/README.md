# Sensor monitor
In this program, it is possible to generate random sensor readings based on min/max and threshold inputs. These readings will be saved to a csv file and the readings are plotted in a line-graph. 
Statistics of these readings are calculated and also written to the csv file.

It is possible to generate new data, or open already existing data from csv files.

## Dependancies
- Python 3.x
- Numpy
- MatPlotLib
